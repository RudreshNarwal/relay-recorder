# Revision presentation

In **Edit recording**, choose source proportions, landscape, portrait or square canvas. Relay fits the full source image inside the canvas; it does not crop away details. Source blur masks apply before canvas fitting. Add up to 30 timed text, arrow or box layers, then preview the edited timeline. Trims, splits, reorder and cleanup remap each layer by its clip occurrence; originals remain unchanged.

Styled captions can be burned into a new revision. Every source requires a ready timed transcript. Overlapping speech becomes consistent combined cues in preview and export. Repeated clips read one transcript snapshot per revision, and publication fails if any source transcript changed during rendering. Selectable VTT/SRT captions remain available. ASS layout-control punctuation is displayed using safe full-width equivalents; transcript text cannot inject layout commands.

Rendering uses production FFmpeg with libass and Noto Sans fonts installed in the server image. The browser preview shows timing, canvas and layer positions; final fonts and text-box geometry can differ. Verify the rendered version before sharing. Burned captions cannot be switched off in that exported version; the preserved source remains available for a new edit.

**Enhance voice** is on by default for new recordings from the Mac recorder, web upload and API (`enhanceAudio`, default `true`). Initial processing applies an 80 Hz high-pass, RNNoise neural denoising through FFmpeg `arnndn` (vendored model in `services/worker/models`, chosen to keep system audio and music better than speech-only models) and `dynaudnorm` leveling. Keyboard, fan and room noise is reduced, not only steady hiss. The uploaded original is never modified; only the published playback, and therefore server transcription, uses the enhanced track. Turn it off in the Mac recorder or the upload dialog for music or studio microphones. Recordings made before this option keep their existing audio. In **Edit recording**, the same two treatments remain opt-in for recordings made without enhancement; edits start from the published playback, so enabling them on an already enhanced recording processes the audio twice. A three-second noise-only render is regression-tested to lose at least 12 dB. In a synthesized-speech check mixed with pink noise, Parakeet transcripts were equivalent before and after enhancement. It has not been benchmarked against Loom.

**Noise suppression** in the Mac recorder (on by default) runs Apple's on-device Voice Isolation (`AUSoundIsolation`, high-quality voice mode) on the microphone while you record, before mixing, so system audio is never processed. The unit adds about 133 ms of delay; Relay shifts microphone timestamps back by that amount to keep lip sync, and the final ~0.13 s spoken just before **Stop** is not captured. If the unit cannot start or fails mid-take, recording continues with the raw microphone and the status line reads "Noise suppression unavailable". A Swift test runs synthesized speech plus noise through the unit in capture-sized chunks: noise fell to silence, speech level was unchanged, and Parakeet transcribed the processed take correctly. Physical microphone and Bluetooth headset checks remain pending.

Choose a thumbnail time and optionally generate a GIF of up to three seconds at 320 pixels wide and 8 fps. Download it from the rendered entry in **Versions**. Static thumbnails remain the default. GIF requests use the same video/revision permissions as playback; an old revision is available only to an editor. No animation autoplays in the library.

Camera background replacement, additional native camera frames, recent-take rewind, interactive audio-effect previews, uploaded custom thumbnails and full visual parity remain unfinished. Native capture permission/device qualification is unchanged. This addition does not claim the entire presentation workstream complete.

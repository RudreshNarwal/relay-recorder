# Speech and cleanup operation

Parakeet is the default. The Mac resolves Auto once at capture: verified/runnable local CoreML, otherwise the private server. Local-only never switches. Browser imports use private-server Parakeet unless the user explicitly selects an external provider. Capture, upload, speech, processing and publication have independent states. Local originals remain until explicit deletion.

Server owners configure speech in web Settings. Create a Deepgram, AssemblyAI or OpenAI configuration, choose a documented model/region, and allow specific workspaces. Save the encrypted key, then explicitly test that saved version. The test sends the bundled 3.094-second synthetic English phrase; provider charges can apply. Successful recognition makes the enabled configuration selectable for its allowed workspaces. Every save increments its version and invalidates verification. No provider or model fallback occurs.

Deepgram `nova-3` and AssemblyAI `universal-3-5-pro` request actual word timing/disfluencies. OpenAI `gpt-4o-transcribe` returns untimed text; `gpt-4o-transcribe-diarize` supplies segment timing. Relay displays the actual returned capability. Untimed text remains searchable and correctable, but has no captions or timed word cuts. External adapters have transport-fixture coverage; live account qualification is pending. Parakeet's 25 documented languages do not imply measured accuracy for every language.

Recording creation pins configuration ID/version. An admitted upload continues after speech settings change; the worker stops external disclosure if its setting, access or lease is revoked. New browser admission rejected with `SPEECH_CONFIGURATION_UNAVAILABLE` permits explicit reselection while retaining the recording identity. On Mac, a confirmed rejection exposes “Use private server Parakeet and retry” for that recording. Each admission attempt clears earlier rejection proof before making a request; an ambiguous response cannot authorize changing an already-admitted choice. Native originals remain available for local playback/export. Uploaded videos can request a new provider attempt from the transcript panel. Manual corrections are never overwritten by automatic attempts. Rendered revisions inherit retained text, timing and correction protection. Missing source speech leaves an explicit incomplete-transcript error and keeps known text visible; complete the source transcripts and render again, or supply a complete corrected transcript. Uncorrected derivatives can be transcribed explicitly from the transcript panel. Editing never inherits permission to send a stitched source to an external provider. Whole-source untimed text survives stitching, but text with no timestamps is omitted after partial cuts because it cannot be safely aligned.

AssemblyAI persists remote IDs before polling. A lost submission response is marked uncertain and is not blindly resubmitted. Reconcile that operation in the provider account before requesting a new attempt. In-flight remote processing may continue after Relay stops polling; Relay does not promise deletion of provider-side audio or cancellation of already accepted billing. Keys, raw provider errors and user audio never enter connection-test logs.

Word-timed speech jobs split long audio into bounded provider windows with two seconds of overlap. Timestamp-adjacent matching words select the seam without deleting genuine repetitions. Segment-only and untimed models use contiguous windows. Existing remote checkpoints retain their original contiguous boundaries. Audio extraction preserves AAC priming/stream offsets and pads the exact window tail; cleanup uses the same clock-preserving extraction. Real FFmpeg 30-minute-boundary and checkpoint-resume tests pass against provider HTTP fixtures. Long-form recognition quality with live providers and real speech remains unqualified. Anonymous speaker labels are scoped per window; Relay does not claim cross-window person identity.

## Acoustic cleanup

The private `/analyze` endpoint shares the pinned Silero model with ASR and uses the same authentication and concurrency gate. Requests contain at most 30 minutes of mono PCM16/16 kHz audio; the worker windows longer revisions. It returns speech intervals plus audible-energy protection, independently of transcript recognition. The private service is not exposed publicly.

The balanced preset keeps 250 ms of a qualifying gap, requires at least 600 ms after protection, and pads speech/transcript/audible intervals by 100 ms. Audible blocks above -60 dBFS protect quiet material, breaths and music. This is a conservative signal threshold, not a music classifier or a guarantee of perfect speech detection. English filler candidates require actual timed words and exclude overlapping speech; unsupported languages get acoustic/manual editing only. Contextual repeat/tangent proposals are optional, send word text to the configured cloud language model, and require review. Cloud failure leaves acoustic proposals available.

Select proposals, compare before/after playback, then apply them to the edit. Undo restores the previous edit. Applying does not render or publish; **Render new version** performs the normal immutable-revision path. Revision and monotonic transcript content version are checked again. Pending privacy blurs and thumbnails follow retained footage through manual trim/split/reorder/delete, transcript cuts and cleanup, with separate identities for repeated occurrences; a limit violation requires fewer cuts. Five-millisecond cut-edge fades retain timeline duration.

Every retained occurrence of a timestamped comment receives a mapped playback position. Replies remain attached. Untimed top-level comments stay on their original revision. Stitching another video's media does not import its private discussion. Chapter titles carry only when their whole chapter range survives, so a cut cannot expose titles describing removed material. Original comments, captions and AI artifacts remain bound to their original revision.

Cleanup is experimental until the consented 30-clip-per-language benchmark and matched Loom premium comparison pass. See the [fixture manifest](../tests/fixtures/cleanup/manifest.json) for evidence and missing gates.

## Upgrades and verification

Schema versions 5–7 add provider settings, speech attempts, truthful transcript metadata, monotonic content versions, cleanup analyses and comment anchors. `pnpm migrate` applies them transactionally under the schema lock. Back up database and media before deployment; preserve encryption keys. Roll back application code before removing new fields/tables, and do not restore an older database over newly captured media.

Run `pnpm startup` to rebuild and launch only the web/server stack; open native apps separately. The API contract is [openapi.json](openapi.json), served at `/api/openapi`. `pnpm test`, `pnpm typecheck`, dedicated API/worker databases, real private-model tests and the opt-in browser test cover this implementation. For browser checks, set `RELAY_BROWSER_TEST_URL` to a running source build, then run `pnpm exec playwright test tests/cleanup-ui.spec.ts --workers=1` after `pnpm exec playwright install chromium --only-shell`.
